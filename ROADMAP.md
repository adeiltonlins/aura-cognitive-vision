# AURA Roadmap

## v0.1 — Cognitive Vision Proof of Concept

Goal: demonstrate the complete loop using ordinary computer hardware.

- [ ] Accept an image from the user
- [ ] Detect visible entities
- [ ] Generate a structured scene model
- [ ] Ask a multimodal model for contextual interpretation
- [ ] Produce confidence-aware observations
- [ ] Render semantic annotations over the original image
- [ ] Expose a simple local/web interface

## v0.2 — Temporal perception

- [ ] Video input
- [ ] Object persistence across frames
- [ ] Scene change detection
- [ ] Short-term visual memory
- [ ] Event timeline

## v0.3 — Spatial cognition

- [ ] 2D/3D coordinates
- [ ] Scene graph
- [ ] Persistent anchors
- [ ] Spatial queries
- [ ] Prototype AR-style overlay

## v0.4 — Agentic cognition

- [ ] Agent orchestration
- [ ] Verification agent
- [ ] Context research agent
- [ ] Planning agent
- [ ] Tool execution boundaries

## v0.5 — Human interface

- [ ] Voice interaction
- [ ] Conversational visual queries
- [ ] Personal preferences
- [ ] Adaptive information density
- [ ] Accessibility modes

## v1.0 — Cognitive Vision Platform

A modular platform where the same cognitive layer can power multiple visual interfaces.

## Long-term research

- wearable cameras and sensors;
- smart glasses;
- AR displays;
- low-latency edge inference;
- privacy-preserving local processing;
- optical display technologies;
- future contact-lens interfaces;
- brain-computer interfaces as a distant research direction.

Hardware claims beyond current prototypes should be treated as research hypotheses, not promises.
